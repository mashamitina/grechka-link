# Ссылка-открытка «Гречки» для Телеграма

Серверы Телеграма не достают до grechka-gym.ru: сайт стоит в России, а сеть между ними режется. Поэтому под ссылкой на
сайт Телеграм не показывает превью. Эта страница лежит на GitHub Pages: Телеграм читает её метки и показывает картинку
с заголовком, а человека сразу переводит на https://grechka-gym.ru (параметры ссылки, например utm, сохраняются).

- `index.html` — заголовок, описание и картинка, как у главной сайта. Поменялись там — поменять и здесь.
- `og-image.jpg` — картинка-превью 1200 × 630, та же, что `web/public/brand/og-image.jpg` в основном репозитории.
- Счётчиков, cookie и форм здесь нет.
